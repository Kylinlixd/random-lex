# random-lex · 随机词条抽取

极简学习工具：词条轮盘 + 三段专注计时 + 浏览器语音朗读。纯静态页面，无依赖、无构建。

## 运行

直接双击打开 `index.html` 即可；或起一个本地服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 功能

- **词条轮盘**：点击「开始抽取」（或按空格），众多词条快速闪动约 2.7 秒后减速落定，滚动滴答音效 + 落定和弦音效。洗牌袋算法保证循环随机、一轮之内不重复，抽完全部自动重新洗牌。
- **词库数据源**：内置 165 条涵盖数学、物理、天文、生物、科学、哲学、心理、经济、技术、生活、概念及英文的词条，首次打开自动缓存到浏览器 `localStorage`。
  - 「词库管理」支持：手动录入/更新、搜索、逐条删除、一键重置内置词库。
  - 批量导入支持多种格式：
    - **粘贴文本**：JSON 数组 `[{term, def, cat}]`，或每行一条（`Tab`、`｜`、`：`、`-` 分隔）
    - **.txt**：每行一条
    - **.csv / .tsv**：表格格式，首行可带表头（自动识别「词条 / 释义 / 分类」列）
    - **.xlsx / .xls**：Excel 表格，动态加载 SheetJS 解析（首次使用时从 CDN 加载，需联网）
  - 支持导入 .txt/.json/.csv/.tsv/.xlsx/.xls 文件、导出 JSON 备份。
  - 「从维基百科抓取」：输入词条名，调用维基百科开放接口（REST summary API，支持 CORS）获取摘要并缓存到本地。
- **专注计时**：学习 / 记忆 / 复述三个滑块，数值真实驱动各阶段时长。学习 10~60 分钟，记忆 5~30 分钟，复述 1~5 分钟，默认 15 / 5 / 1。按顺序自动切换阶段；点击开始有提示音，阶段切换与全部完成各有音效；滑块设置持久化，旧版（含番茄钟个数制）设置会自动迁移。
- **TTS 朗读**：词条卡片上的「朗读」按钮用 Web Speech API 朗读词条与释义，中英文自动选择语音。
- 所有数据（词库、抽取进度、滑块设置）均保存在浏览器 `localStorage`，可随时导出备份。

| `style.css` | 极简单色编辑风样式 |
